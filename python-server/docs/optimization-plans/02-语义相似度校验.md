# 优化项：语义相似度校验 — 避免"有词但无关"的误判

## 当前状态

纯子串匹配：只要问题中出现关键词就认为命中。存在误判场景。

## 问题示例

```
用户问："宝宝不爱吃退烧药怎么办"
  → 子串命中 "退烧" → 判为 illness（疾病）
  → 实际意图：feeding（喂养/喂药困难）
```

关键词命中了，但句子整体的语义和"疾病"不相关。

---

## 改进方案

在子串匹配的基础上，增加语义相似度校验。如果问题向量和意图的典型向量相似度过低，说明"虽然命中关键词但整体语义不相关"，应降权或忽略。

### 离线：为每个意图建一个"语义锚点"

对每个领域的所有关键词取 embedding，算平均向量。

### 在线：命中后计算问题 vs 意图向量的余弦相似度

用综合分代替纯关键词分：

```
final_confidence = keyword_confidence × semantic_similarity
```

---

## 代码

```python
"""
语义校验模块 — 为意图路由增加词向量相似度校验

集成方式（渐进式）：
    1. 本文件独立存在，不影响现有 classify_by_keyword
    2. 在 route_intent 中加一行调用即可启用

使用：
    from docs.optimization_plans.semantic_validator import SemanticValidator
    validator = SemanticValidator()
    ...
"""

import numpy as np


class SemanticValidator:
    """
    语义校验器 — 判断问题和某个意图在语义上是否真的相关。

    原理：
        1. 对每个意图的所有关键词取 embedding 均值，作为该意图的"语义锚点"
        2. 新问题来时，算问题和锚点的余弦相似度
        3. 相似度 < 0.5 → 子串命中可能是噪声 → 降权
    
    依赖：
        app.services.rag.get_embedding() — 调 Ollama 的 bge-m3
    """

    # 相似度低于此值 → 认为子串命中不可信
    SEMANTIC_THRESHOLD = 0.5

    def __init__(self):
        from app.services.rag import get_embedding
        from app.services.intent_router import KEYWORD_RULES

        self._get_embedding = get_embedding
        self._intent_anchors: dict[str, np.ndarray] = {}
        self._build_anchors(KEYWORD_RULES)

    # -----------------------------------------------------------
    # 离线：构建语义锚点
    # -----------------------------------------------------------

    def _build_anchors(self, keyword_rules) -> None:
        """
        为每个意图计算语义锚点（所有关键词 embedding 的平均值）。

        仅初始化时执行一次，耗时取决于关键词总数（约 100-150 个词，
        每个 embedding 约 10ms，总计约 1-2 秒）。
        """
        for rule in keyword_rules:
            embeddings = []
            for kw in rule.keywords:
                try:
                    emb = self._get_embedding(kw)
                    embeddings.append(emb)
                except Exception:
                    # Ollama 偶发超时，跳过单个词不影响整体
                    pass

            if embeddings:
                # 平均向量 = 该意图的"典型语义"
                anchor = np.mean(embeddings, axis=0)
                self._intent_anchors[rule.intent] = anchor
                print(f"[SemanticValidator] 已构建 '{rule.intent}' 锚点 "
                      f"({len(embeddings)} 个词)")

    # -----------------------------------------------------------
    # 在线：计算语义相似度
    # -----------------------------------------------------------

    def similarity(self, question: str, intent: str) -> float:
        """
        计算问题和某个意图的余弦相似度。

        Returns:
            0.0 ~ 1.0。越高说明问题越符合该意图的语义特征。
        """
        if intent not in self._intent_anchors:
            return 1.0  # 没有锚点 → 不校验，信任关键词

        try:
            q_emb = self._get_embedding(question)
            anchor = self._intent_anchors[intent]

            # 余弦相似度
            dot = np.dot(q_emb, anchor)
            norm_q = np.linalg.norm(q_emb)
            norm_a = np.linalg.norm(anchor)

            if norm_q == 0 or norm_a == 0:
                return 0.0

            return float(dot / (norm_q * norm_a))
        except Exception:
            # embedding 失败 → 降级，信任关键词
            return 1.0

    # -----------------------------------------------------------
    # 综合评分
    # -----------------------------------------------------------

    def validate(
        self,
        question: str,
        intent: str,
        keyword_confidence: float,
    ) -> tuple[float, float]:
        """
        校验一次关键词命中。

        Args:
            question:           用户原始问题
            intent:             被命中的意图
            keyword_confidence: 纯关键词算出的置信度

        Returns:
            (final_confidence, semantic_similarity)
              - final_confidence: 综合置信度（关键词 × 语义）
              - semantic_similarity: 语义相似度原始值（调试用）
        """
        sim = self.similarity(question, intent)

        if sim < self.SEMANTIC_THRESHOLD:
            # 语义不相关 → 大幅降权
            final = keyword_confidence * sim
        else:
            # 语义相关 → 保持原分
            final = keyword_confidence

        return final, sim
