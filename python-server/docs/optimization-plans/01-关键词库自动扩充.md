# 优化项：关键词库自动扩充

## 当前状态

6 类意图，每类约 10-25 个手工编写的种子关键词。新增关键词完全靠人工经验。

## 改进方向

从 ChromaDB 知识库中自动提取高频词，补充到手写关键词列表中。

---

## 方案

对每个领域的 collection 文档做 jieba 分词 + 词频统计，取 Top-N 高频词作为候选关键词，人工审核后加入 `KEYWORD_RULES`。

### 步骤

1. 从 `SEARCH_COLLECTIONS` 遍历每个 collection，用 `coll.get()` 拿全量文档
2. jieba 分词，过滤停用词和长度 < 2 的单字
3. 用 `Counter` 统计词频，取 Top-N
4. 和当前 `KEYWORD_RULES` 中的手写关键词对比，找出"高频但未收录"的候选词
5. 人工审核后加入

---

## 代码

```python
"""
关键词自动提取工具 — 从 ChromaDB 知识库中提取高频候选关键词

使用方式：
    cd python-server
    python -m docs.optimization-plans.keyword_extractor

输出：每个领域的高频词 TOP-30，标注哪些已收录、哪些是候选新词。
"""

import jieba
from collections import Counter

# 复用现有模块
from app.services.rag import chroma_client
from app.core.config import SEARCH_COLLECTIONS
from app.services.intent_router import KEYWORD_RULES, Intent


# -----------------------------------------------------------
# 配置
# -----------------------------------------------------------

# 停用词 — 高频但对意图分类无意义的词
STOPWORDS = {
    "的", "了", "是", "在", "和", "就", "都", "也", "不", "要",
    "可以", "如果", "或者", "因为", "所以", "但是", "而且", "然后",
    "什么", "怎么", "怎样", "为什么", "多少", "哪些", "哪个",
    "宝宝", "孩子", "小孩", "婴儿", "幼儿", "新生儿",
    "问题", "回答", "建议", "情况", "可能", "一般", "通常", "出现",
    "需要", "注意", "一定", "比较", "特别", "非常", "有些", "很多",
    "一个", "这个", "那个", "一些", "这些", "那些",
}

# 最少出现次数 — 低于此值的关键词不够"高频"，不值得收录
MIN_COUNT = 3

# 最少词长度 — 过滤单字（"烧"、"咳" 虽然在用但由手写保证）
MIN_WORD_LEN = 2


# -----------------------------------------------------------
# 工具函数
# -----------------------------------------------------------

def tokenize(text: str) -> list[str]:
    """jieba 分词 + 过滤停用词 + 过滤单字"""
    words = jieba.cut(text)
    return [
        w for w in words
        if len(w) >= MIN_WORD_LEN
        and w not in STOPWORDS
    ]


def get_existing_keywords(intent: Intent) -> set[str]:
    """获取某个意图当前已收录的所有关键词"""
    for rule in KEYWORD_RULES:
        if rule.intent == intent:
            return set(rule.keywords)
    return set()


def extract_candidates(
    intent: Intent,
    docs: list[str],
    top_n: int = 30,
) -> dict:
    """
    从文档列表中提取高频候选关键词。

    Returns:
        {
            "intent": str,
            "total_docs": int,
            "top_words": [
                {"word": str, "count": int, "in_rule": bool},
                ...
            ],
            "new_candidates": [str, ...],  # 未收录的高频词
        }
    """
    # 词频统计
    all_words = []
    for doc in docs:
        all_words.extend(tokenize(doc))

    counter = Counter(all_words)

    # 获取当前已收录的关键词
    existing = get_existing_keywords(intent)

    # Top-N
    top_words = []
    new_candidates = []
    for word, count in counter.most_common(top_n):
        in_rule = word in existing
        top_words.append({
            "word": word,
            "count": count,
            "in_rule": in_rule,
        })
        if not in_rule and count >= MIN_COUNT:
            new_candidates.append(word)

    return {
        "intent": intent,
        "total_docs": len(docs),
        "top_words": top_words,
        "new_candidates": new_candidates,
    }


# -----------------------------------------------------------
# 主流程
# -----------------------------------------------------------

def run():
    """遍历所有 collection，为每个意图输出候选关键词"""

    # 按意图名建索引，方便分类
    # | collection 名 | 对应意图 |
    # |--------------|---------|
    # | rag_medical   | illness |
    # | rag_samples   | 混合    |
    #
    # 注意：当前 ChromaDB 中的 collection 是 rag_medical 和 rag_samples，
    # 不按意图分。这里的示例假设未来按意图分 collection。
    #
    # 实际使用时可以：
    #   1. 如果 collection 已经按意图建好 → 直接映射
    #   2. 如果没有 → 对所有文档做主题建模，或人工标注一批后跑

    print("=" * 60)
    print("关键词候选词提取")
    print("=" * 60)

    for coll_name in SEARCH_COLLECTIONS:
        coll = chroma_client.get_or_create_collection(name=coll_name.strip())
        results = coll.get(include=["documents"])
        docs = results.get("documents", [])

        if not docs:
            print(f"\n[{coll_name}] 无文档，跳过")
            continue

        print(f"\n[{coll_name}] 共 {len(docs)} 篇文档")

        # 分词（所有文档合在一起）
        all_words = []
        for doc in docs:
            all_words.extend(tokenize(doc))

        counter = Counter(all_words)
        print(f"  去重词数: {len(counter)}")
        print(f"  Top-30 高频词:")

        for word, count in counter.most_common(30):
            # 检查是否已在某个意图规则中
            found_in = []
            for rule in KEYWORD_RULES:
                if word in rule.keywords:
                    found_in.append(rule.intent)
            status = f"已收录({','.join(found_in)})" if found_in else "★ 候选"
            print(f"    {word:12s}  ({count:3d}次)  {status}")


# -----------------------------------------------------------
# CLI 入口
# -----------------------------------------------------------

if __name__ == "__main__":
    run()
```

## 集成到规则库的步骤

1. 跑一次 `keyword_extractor.py`
2. Review `★ 候选` 标记的词，去掉不相关的（如"物理降温"相关但对分类帮助不大）
3. 手动添加到 `intent_router.py` 的 `KEYWORD_RULES` 对应领域数组中
4. 重启服务生效
