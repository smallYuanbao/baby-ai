# 优化项：多意图处理

## 当前状态

单意图：每个问题只分到一个意图标签。多条规则同时命中时只取最高分。

## 问题示例

```
用户问："宝宝发烧不爱吃奶怎么办"
  → illness(0.92) 和 feeding(0.92) 同时命中
  → 当前方案只保留一个（illness）
  → 但回答应该兼顾疾病护理 + 喂养建议
```

---

## 改进方案

关键词匹配从"只取最高分"改为"取所有超阈值的意图"。System Prompt 拼接时合并多个领域的附加指令。

### 核心变化

| | 当前（单意图） | 改进后（多意图） |
|---|---|---|
| classify_by_keyword 返回 | 单个 IntentResult 或 None | list[(Intent, confidence)] |
| 匹配逻辑 | `if conf > best_conf: 替换` | `if conf >= threshold: 追加` |
| System Prompt | 单个 INTENT_APPENDS | 多个 INTENT_APPENDS 依次拼接 |
| 阈值 | 0.8（单意图采纳线） | 0.6（多意图候选线，更低以纳入次相关意图） |

---

## 代码

```python
"""
多意图路由 — classify_by_keyword 的多标签版本

集成方式：
    1. 本文件中的 classify_by_keyword_multi 替代原单意图版本
    2. route_intent 增加多意图分支
    3. build_multi_intent_prompt 合并多个领域的 System Prompt
"""

from typing import Optional
from app.models.chat import ChatMessage
from app.services.intent_router import (
    Intent,
    IntentResult,
    KEYWORD_RULES,
    BASE_PROMPT,
    INTENT_APPENDS,
    VALID_INTENTS,
    classify_by_llm,
)


# -----------------------------------------------------------
# 配置
# -----------------------------------------------------------

# 多意图关键词匹配的阈值（低于单意图的 0.8，纳入次要意图）
MULTI_INTENT_THRESHOLD = 0.6

# 多意图采纳阈值 — 超过此值且只有 1 个意图时直接采纳
MULTI_INTENT_HIGH_CONF = 0.9


# -----------------------------------------------------------
# 1. 多标签关键词匹配
# -----------------------------------------------------------

def classify_by_keyword_multi(
    question: str,
    threshold: float = MULTI_INTENT_THRESHOLD,
) -> list[tuple[Intent, float]]:
    """
    返回所有超过阈值的意图，按置信度降序排列。

    与单意图版本的区别：
      - 不取 max，取 all(conf >= threshold)
      - 返回列表而非单个结果

    Example:
        >>> classify_by_keyword_multi("宝宝发烧不爱吃奶")
        [("illness", 0.92), ("feeding", 0.92)]
    """
    hits = []

    for rule in KEYWORD_RULES:
        matched = [kw for kw in rule.keywords if kw in question]
        if not matched:
            continue

        confidence = min(rule.confidence + len(matched) * 0.02, 1.0)

        if confidence >= threshold:
            hits.append((rule.intent, confidence))

    # 按置信度从高到低
    hits.sort(key=lambda x: x[1], reverse=True)
    return hits


# -----------------------------------------------------------
# 2. 多意图 System Prompt 拼接
# -----------------------------------------------------------

def build_multi_intent_prompt(intents: list[tuple[Intent, float]]) -> str:
    """
    合并多个领域的附加指令。

    规则：
      - emergency 独占（急救不需要其他领域干扰）
      - 其他意图依次拼接 BASE_PROMPT + APPEND_1 + APPEND_2 + ...

    Example:
        >>> build_multi_intent_prompt([("illness", 0.92), ("feeding", 0.92)])
        # 返回 BASE_PROMPT + INTENT_APPENDS["illness"] + INTENT_APPENDS["feeding"]
    """
    # 急救模式 — 最高优先级，独立 prompt
    if intents and intents[0][0] == "emergency":
        return INTENT_APPENDS["emergency"]

    prompt = BASE_PROMPT

    for intent, confidence in intents:
        append = INTENT_APPENDS.get(intent, "")
        if append:
            prompt += "\n\n" + append

    return prompt


# -----------------------------------------------------------
# 3. 多意图路由入口
# -----------------------------------------------------------

def route_intent_multi(question: str) -> IntentResult:
    """
    多意图路由 — 双层分诊策略的多标签版本。

    决策树：
        keyword 命中多个且都高置信 → 多意图直接采纳
        keyword 命中 1 个且高置信   → 单意图直接采纳
        keyword 低置信 / 未命中     → LLM 分类
        LLM 分类结果                → 单意图
    """
    keyword_hits = classify_by_keyword_multi(question)

    # ---- 无关键词命中 → LLM ----
    if not keyword_hits:
        llm_intent = classify_by_llm(question)
        prompt = INTENT_APPENDS.get(llm_intent, "")
        if llm_intent != "emergency":
            prompt = BASE_PROMPT + prompt
        return IntentResult(
            intent=llm_intent,       # type: ignore
            confidence=0.8,
            source="llm",
            prompt=prompt,
        )

    top_intent, top_conf = keyword_hits[0]

    # ---- emergency 直接走 ----
    if top_intent == "emergency":
        return IntentResult(
            intent="emergency",       # type: ignore
            confidence=top_conf,
            source="keyword",
            prompt=INTENT_APPENDS["emergency"],
        )

    # ---- 单意图 + 高置信 → 直接采纳 ----
    if len(keyword_hits) == 1 and top_conf >= MULTI_INTENT_HIGH_CONF:
        prompt = BASE_PROMPT + INTENT_APPENDS.get(top_intent, "")
        return IntentResult(
            intent=top_intent,       # type: ignore
            confidence=top_conf,
            source="keyword",
            prompt=prompt,
        )

    # ---- 多意图 或 低置信单意图 → LLM 复核意图列表 ----
    intent_list = [i for i, _ in keyword_hits]
    print(f"[多意图路由] 候选: {intent_list} → LLM 复核")

    llm_intent = classify_by_llm(question)

    # LLM 确认的意图如果在候选列表中 → 用多意图 prompt
    confirmed_intents = [
        (i, c) for i, c in keyword_hits
        if i == llm_intent or c >= MULTI_INTENT_THRESHOLD
    ]

    if not confirmed_intents:
        confirmed_intents = [(llm_intent, 0.8)]

    prompt = build_multi_intent_prompt(confirmed_intents)

    return IntentResult(
        intent=llm_intent,        # type: ignore
        confidence=0.8,
        source="llm",
        prompt=prompt,
    )
